# Python INA228 viewer

Первый настольный просмотрщик для CH582/I2C2USB.

Запуск:

```text
python ina228_viewer.py
```

Зависимость:

```text
python -m pip install pyserial
```

В Windows можно запустить `run_ina228_viewer.bat`. Нужен Python 3.10+ с
рабочим Tcl/Tk (обычная установка Python с python.org его включает).

Возможности текущей версии:

- отдельный поток приёма USB-COM;
- INA228 с текущим протоколом пакета `U(3) + I(3) + DIO(1)`;
- выбор скорости INA228 без перепрошивки;
- окно `ADC Config`: диапазон шунта 163.84/40.96 mV, I/U offset и коэффициенты;
- быстрые графики напряжения, тока и восьми DIO;
- Raw data с кольцевым окном последних 5 секунд;
- режим `ADC codes` для вывода raw-отсчётов без пересчёта в физические единицы;
- синхронное колесо мыши и перетаскивание графиков;
- сохранение принятых raw-данных в CSV.

Настройки калибровки сохраняются в `ina228_viewer.json` рядом со скриптом.
Прошивка не изменяется. Скорость и диапазон шунта передаются командой `CMD_DEV_CFG`.
UART пока не включён: в текущей прошивке `USE_UART_DEV = 0`, поэтому сначала
проверяется производительность INA228/DIO в отдельном приложении.
